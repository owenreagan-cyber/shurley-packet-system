## Conflict Resolution Rules (For Build Phase)

1. **Student sentences:** Always Guided Notes (28 classification + write-your-own L1–5).
2. **Definitions, questions, labels, Q&A scripts:** Teacher Manual over slides over proposed checklist.
3. **Classroom Practice / Checkup / Test sentences:** Teacher oral keys only — never auto-embed in packet.
4. **When TM silent and GN blank:** Mark **TEACHER VERIFY** — do not invent Shurley terms.
5. **Mover & Shaker / Revision / Blueprint building:** Teacher notes + writing sections; not classification drill unless TM specifies.
