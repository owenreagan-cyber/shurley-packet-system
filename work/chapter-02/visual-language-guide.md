## Blueprint Theme Overview

Chapter 2 uses a **construction / blueprint** metaphor throughout slides and posters:

- **Sentence Blueprint** — the full classified sentence diagram
- **Pattern Zone** — left region showing word-pattern sequence (SN V Adv Adv…)
- **Construction Zone** — right region showing the sentence with color-coded labels beneath each word
- **Operation Pattern 1** — detective/investigation theme for SN–V introduction
- **Construction Site** — building metaphor for full-pattern integration (L6)
- **Inspector's Checklist** — five-part sentence completeness check (L3)

Visuals are **functional references**, not decoration. Every diagram should connect to a classification or Q&A step students perform in the packet.

## Color Coding System

Confirmed across T2 posters and T3 slides:

| Label | Color | Hex (approx.) | Usage |
|-------|-------|---------------|-------|
| **SN** | Blue | `#2563EB` range | Subject noun labels, blocks, underlines |
| **V** | Red | `#DC2626` range | Verb labels, blocks, underlines |
| **Adj** | Yellow / Gold | `#EAB308` range | Adjective labels, blocks |
| **Adv** | Green or Purple | `#16A34A` / `#9333EA` | Adverb labels, blocks (deck varies) |
| **A** | Yellow / Teal | `#EAB308` / `#0D9488` | Article adjective blocks |

### Print Rules

- Use consistent colors across all Chapter 2 pages — match poster palette
- Ensure sufficient contrast for grayscale printing (label text must remain readable)
- Do not rely on color alone — always pair color block with abbreviation text (SN, V, etc.)
- Chapter 1 precedent: color is instructional, not decorative

## Layout Zones

### Pattern Zone (Left)

Shows the **pattern sequence** without the full sentence:

```
P1:  SN — V
L2:  SN — V — Adv — Adv
L4:  Adj — Adj — SN — V — Adv — Adv
L5:  A — Adj — Adj — SN — V — Adv — Adv
```

- Horizontal blocks connected by dashes or lines
- Pattern label (P1) shown above or beside
- Used in Learn sections and Memory Checks

### Construction Zone (Right)

Shows the **actual sentence** with labels beneath each word:

```
Those    five    cargo   ships   sailed   slowly   away   today.
[Adj]    [Adj]   [SN]    [V]     [Adv]    [Adv]
```

- Each word sits above its label block
- Labels use color-coded rectangles
- Slash (The Divide) placed directly before the verb in some slides

### Standard Slide Format

Most blueprint slides use a two-zone layout:

| Left (Pattern Zone) | Right (Construction Zone) |
|---------------------|---------------------------|
| Pattern blocks | Sentence + labels |
| Abbreviation sequence | Color-coded word analysis |

When redrawing for print, preserve this left/right relationship.

## Marking Conventions

### The Divide

- Vertical slash placed **directly in front of the verb**
- Separates subject (left) from predicate (right)
- Introduced in L7 slides; useful from L1 in teacher modeling

Example: `Those five cargo ships / sailed slowly away today.`

### Label Placement

- Label sits **directly under** the word it describes
- One label per classified word
- Pattern abbreviations only (SN, V, Adv, Adj, A) — no invented labels

### Intensifier Marking

- Words like **very**, **extremely**, **quite** → labeled **Adv**
- Arrow or note showing Adv modifies the adjacent **Adj** (not the verb)
- Example: `The very soothing music` → very=Adv, soothing=Adj

### Sentence Type Labels

- Placed after full word classification
- Use **D**, **Imp**, **Int**, **E** — not spelled-out names in classification lines
- End Mark Flow: end mark → feeling → type name → abbreviation

### Mover/Shaker Marking

- Original adverb position shown with strikethrough or arrow
- Moved adverb at front with **comma** after it
- Example: `Slowly, the ships sailed away today.`

## Q&A Flow Visual Language

### Interrogation Protocol (Slides)

Visual sequence for oral instruction:

```
Step 1:  WHO? or WHAT?  →  find SN
Step 2:  What is being said about [SN]?  →  find V
Step 3:  (if adverbs) HOW? WHEN? WHERE?  →  find Adv
Step 4:  (if adjectives) WHAT KIND? WHICH ONE? HOW MANY?  →  find Adj
Step 5:  (if articles)  a / an / the  →  find A
```

Represent in packet as a numbered vertical flow or sidebar callout — not a paragraph.

### 4 Steps to Classify (Poster)

From `Mastering_the_Sentence_Blueprint.png`:

1. Ask the question
2. Name the word
3. Identify its job
4. Label with the correct abbreviation

Use as Memory Check or reference footer.

## Print Adaptation Rules

### From Slides to Packet

| Rule | Detail |
|------|--------|
| Strip branding | Remove NotebookLM logos/watermarks from all redrawn diagrams |
| Simplify | Slides may have decorative backgrounds — use clean white/light gray for print |
| Scale | Diagrams must remain readable at 8.5 × 11; minimum label text 10 pt |
| Writing space | Classification practice pages need generous blank lines beneath each sentence — diagrams go in Learn/reference, not crowding practice |
| Intentional placement | Each visual appears adjacent to the skill it teaches — not grouped decoratively |
| Teacher vs student | Answer-marked diagrams → teacher edition only |

### From Posters to Packet

| Poster | Adaptation |
|--------|------------|
| Core Five | Full-width reference insert (page 2 or 3 of packet) |
| Mastering | Optional bookmark or teacher-edition intro; sentence-type section may merge into Core Five spread |
