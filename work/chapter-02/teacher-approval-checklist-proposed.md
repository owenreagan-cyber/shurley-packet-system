### Teacher edition presentation (proposed)

- Place labels **directly above each classified word** in the workspace (Chapter 1 teacher edition uses bold blue `#1F4E79` per `docs/standards/packet-design-rules.md`).
- Pattern string shown separately (e.g., `A Adj Adj SN V Adv Adv`) — CONFIRMED FROM SOURCE structure.

### Notes on multi-word / multiple adjective or adverb handling

| Situation | Proposed handling | Label |
|-----------|-------------------|-------|
| Full pattern sentence (L5+) | Label **every** classifiable word; one label per word above the word | LIKELY / TEACHER VERIFY |
| Fewer adjectives than two slots (e.g., “The girls giggled loudly.”) | Label **The** = A, **girls** = SN; leave unused Adj slots blank in pattern row; do not invent filler adjectives | LIKELY / TEACHER VERIFY |
| More than two adverbs in a sentence (e.g., “…slowly away today”) | Label the two adverbs that match classroom Shurley oral practice for that lesson; document choice in teacher key | TEACHER MUST SUPPLY |
| Compound subject nouns (e.g., “cargo ships”) | **cargo** = Adj, **ships** = SN | LIKELY / TEACHER VERIFY |
| Article + adjective stack (e.g., “Several angry bees”) | **Several** = A, **angry** = Adj, one Adj slot blank OR **Several** = Adj if teacher treats quantifiers as adjectives — confirm Shurley convention | TEACHER MUST SUPPLY |
| Multiple adjectives before SN | Label each adjective **Adj** in order left to right | LIKELY / TEACHER VERIFY |
| Multiple adverbs | Label each adverb **Adv** in order; if pattern row shows only two Adv slots, teacher key should state which two are required for that item | TEACHER MUST SUPPLY |
